# Raksha Atlas

## Start locally
1. Start Docker Desktop.
2. Open the project folder in PowerShell.
3. Run `docker compose up -d --build`.
4. Open http://localhost:8080.
5. Check services: `docker compose ps`.

Stop safely with `docker compose down`. Never use `docker compose down -v` for a normal shutdown.
