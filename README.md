# Defence

## Start
1. Start Docker Desktop.
2. Open this folder in PowerShell.
3. Run `docker compose up -d --build`.
4. Open http://localhost:8080.
5. Check: `docker compose ps`.

Stop safely: `docker compose down`.
Never use `docker compose down -v` for a normal shutdown.

For project architecture, development history and next steps, read
`README-HANDOFF.md`.
