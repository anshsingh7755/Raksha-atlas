# Archived documentation index

The former documentation index linked the architecture, roadmap, development history, frontend, backend, AI/RAG, inventory, Docker, database, data engineering, infrastructure, scripts and public research guides.

Detailed reference material remains in the corresponding folders under `docs/`, `database/`, `infrastructure/`, `scripts/` and `data-engineering/`.

Status terminology used by the former index:
- Active: used by the running application.
- Supporting: assists the active application.
- Migration scaffold: prepared for possible future replacement.
- Planned: future work, not necessarily implemented.
- Pending validation: implementation exists but required checks are incomplete.
- Completed: implementation and acceptance checks have evidence.

When code changes, update the relevant detailed guide, architecture, roadmap and history as applicable. Record tests only when actually run.
